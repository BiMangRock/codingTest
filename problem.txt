다음 자릿수보다 작은 첫 번째 위치 찾기
○ 문제 설명
숫자 문자열 number가 주어집니다. 왼쪽(인덱스 0)부터 오른쪽으로 차례대로 살펴보며, **바로 오른쪽에 있는 숫자보다 크기가 작은 첫 번째 숫자의 위치(인덱스)**를 찾으려고 합니다.
만약 모든 숫자를 확인했을 때 바로 오른쪽 숫자보다 작은 숫자가 존재하지 않는다면(즉, 숫자가 계속 같거나 작아지는 경우), 가장 마지막 숫자의 위치(인덱스)를 반환합니다.
문자열 number가 solution 함수의 매개변수로 주어질 때, 조건에 맞는 숫자의 인덱스(0부터 시작)를 정수 형태로 return 하도록 solution 함수를 완성해 주세요.
○ 제한 조건
number는 2자리 이상, 100,000자리 이하인 숫자 문자열입니다.
결과로 반환하는 값은 0부터 시작하는 인덱스 번호(정수)입니다.
○ 입출력 예
number = "1924"
→
→
 0
인덱스 0의 '1'은 오른쪽의 '9'보다 작으므로 조건에 맞는 첫 번째 위치는 0입니다.
number = "9824"
→
→
 2
9 > 8 (만족 안 함)
8 > 2 (만족 안 함)
인덱스 2의 '2'는 오른쪽의 '4'보다 작으므로 조건에 만족하는 첫 번째 위치는 2입니다.
number = "4321"
→
→
 3
오른쪽 숫자보다 작은 숫자가 존재하지 않으므로 가장 마지막 숫자의 인덱스인 3을 반환합니다.
